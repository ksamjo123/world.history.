# 동기 연표 (Synchronological Chart)

주후 1년부터 현재까지, 신학·철학·정치·과학·예술과 세계 각 지역에서
무엇이 동시에 일어났는지를 한 장에 놓고 비교하는 정적 웹사이트.
개혁주의 관점을 밝히고 엮었다.

## 파일 구조

    index.html   화면 뼈대와 탭

    perspective.html   관점·용어·서지 방침 선언
    t/*.html  s/*.html  p/*.html   문턱 · 계보 · 인물

고친 뒤 `node build.js`를 한 번 돌리면 정적 문서가 함께 갱신된다.

### 사건 항목의 필드

    {
      "y":  1647,                        연도 (필수)
      "t":  "오웬 『죽음의 죽음』",          제목 (필수)
      "n":  "그리스도의 속죄가 …",          사실 기술 (필수)
      "r":  2,                           등급 - 배율에 따른 표시 층
      "k":  "Owen 제한속죄 DeathOfDeath",  검색용 이명·별칭
      "i":  "가능성을 만든 것인지 …",       개혁주의적 읽기 (해석)
      "dt": "1647년에 출간되었고 …",        연대에 관하여 (출처와 불확실성)
      "x":  { q, a, b, r, w }            쟁점 (아래 참조)
      "id": "th1646",                    식별자 (자동 부여, 손대지 말 것)
      "l":  [["th1647","계보 이름"]]      이어진 사건 [상대 id, 관계 설명]
    }

`r` 등급: 1 = 항상 보임 · 2 = 배율 1.3배부터 · 3 = 2.2배부터.
생략하면 2로 처리된다. 레인마다 1급이 15~25%가 되게 유지할 것.
한 레인이 1급 없이 비면 세로 기준선으로 동시대를 비교하는 기능이 죽는다.

`x` 쟁점:

    "x": {
      "q": "무엇이 다투어지는가",
      "a": "이 연표의 읽기",
      "b": "다른 읽기 - 상대가 실제로 말하는 대로",
      "r": "응답 - 왜 그렇게 보는가",
      "w": "core | error | view"       경계 등급, 정치사에는 붙이지 않음
    }

`w` 등급: core 근본 교리(진홍) · error 근거가 약한 견해(황토) ·
view 개혁주의 안에서도 갈림(회청). 생략하면 중립 표기가 된다.

## 연결

항목에 커서를 올리거나 누르면 `l`에 적힌 사건들과 곡선으로 이어지고
나머지는 흐려진다. 등급 때문에 숨어 있던 상대도 이때 드러난다.

연결은 양방향이어야 한다. `a`가 `b`를 가리키면 `b`도 `a`를 가리켜야 하며,
시험이 이를 검사한다. 손으로 넣기보다 스크립트로 양쪽에 함께 쓰는 편이 안전하다.

계보와 문턱과 영향 흐름에서 자동으로 도출한 연결이 140쌍, 손으로 이은 것이
62쌍이다. 손으로 잇는 것은 자동으로는 나오지 않는 교차 연결
— 나라를 가로지르거나 사조를 가로지르는 것 — 에 집중할 것.

## 서술 원칙

1. **사실은 논쟁 없는 범위로.** 교회사 개론에서 다루는 수준만 담는다.
2. **사실(n)과 해석(i)을 절대 한 필드에 섞지 않는다.** 화면에서 둘을
   눈으로 구분할 수 있게 두는 것이 이 사이트의 설계 원칙이다.
3. **해석은 고백에서만.** i에는 개혁주의 신앙고백에서 따라 나오는 읽기만
   적는다. 특정 학자의 학설을 옮기지 않는다.
4. **인용과 쪽수는 달지 않는다.** 검증되지 않은 서지는 없는 것보다 나쁘다.
5. **반대 견해는 그 견해가 실제로 말하는 대로 적는다.** 약하게 고쳐 적고
   반박하면 아무것도 반박하지 못한 것이다.
6. **층위를 섞지 않는다.** 관찰과 전제, 창조의 날과 아담의 역사성처럼
   무게가 다른 것을 한 쟁점에 묶지 않는다.
7. **타 전통은 기술하되 평가하지 않는다.**
8. **우리 편도 예외가 아니다.** 자기 진영의 잘못을 축소하지 않는다.

새 항목을 넣을 때 "이건 학계에서 다투는 문제인가"를 먼저 물을 것.
다툰다면 넣지 않거나, 사실만 넣고 판단은 쟁점 칸으로 뺀다.

## 용어 원칙

성경(성서 아님) · 칼빈(칼뱅 아님) · 어거스틴 · 터툴리안 · 오리겐 ·
안셀름 · 제롬 · 튜레틴 · 면죄부(면벌부 아님) · 성례(성사 아님) ·
헬라어(그리스어 아님) · 주후(기원후 아님).

초대교회의 직분은 「감독」, 가톨릭·정교회·성공회의 제도는 그쪽 용어인
「주교」·「대주교」·「총대주교」를 그대로 쓴다.

근거는 perspective.terms에 있고 화면의 「역사관」 탭에 그대로 뜬다.
바뀐 옛 표기는 각 항목의 k에 남겨 두었으므로 「칼뱅」이나 「성서」로
검색해도 찾힌다. 새 항목에도 학계 표기를 k에 같이 적을 것.

> **주의 1.** 같은 해에 항목이 둘 이상인 지점이 20곳 넘게 있다. 스크립트로
> 항목을 찾을 때 연도만으로 find 하면 엉뚱한 항목을 덮어쓴다. 반드시
> 제목까지 함께 지정할 것. 실제로 1907년 「독노회」 내용이 「평양 대부흥」에
> 덮어씌워진 사고가 있었다.
>
> **주의 2.** 용어를 일괄 치환할 때 단어 안쪽까지 바뀌지 않는지 반드시
> 확인할 것. 과거에 「천주교회」가 「천감독회」로, 「성서를」이 「성경를」로
> 깨진 적이 있다. 받침 유무가 바뀌면 조사도 함께 고쳐야 한다.

## 항목 추가하기

사건 하나:

    {"y":1647,"t":"오웬 『죽음의 죽음』",
     "n":"그리스도의 속죄가 누구를 위한 것인가를 다룬다.",
     "r":2,"k":"Owen 제한속죄 DeathOfDeath",
     "i":"가능성을 만든 것인지 구원을 성취한 것인지가 쟁점입니다."}

레인 하나:

1. data.js에 새 배열을 만든다 - "music": [ … ]
2. lanes 배열의 원하는 자리에 한 줄 넣는다
   {"id":"music","t":"음악","s":"","c":"#7B4650","k":"ev","src":"music"}

레인의 k(종류)는 넷 중 하나: ev 시점 사건 · span 기간 · th 문턱 · flow 화살표

## 정기 점검

내용을 크게 늘린 뒤에는 아래를 확인할 것.

- 설명(n)이 빈 항목이 없는지
- 같은 사건이 두 레인에 다른 제목으로 들어가 있지 않은지
- 계보와 문턱이 가리키는 연도에 실제 항목이 있는지
- 레인마다 1급이 충분한지
- 용어 치환의 부작용과 조사 오류가 없는지
